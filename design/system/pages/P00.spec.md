# P00 · 登录

> **使用说明**：本页是匿名 → 正式账号的关键转换点。
> ⚠️ **铁律 1 例外**：微信一键登录按钮使用 `--tkn-color-brand-wechat` (#07C160) 微信品牌色，**必须** `data-iron-rule-1-exception="wechat-brand"` 显式标注。

---

## §1 页面目的（why · 1 句话）

让访客 / 游客在 1 步内完成登录或注册，并自动 claim 之前的 guest_session（如有），承载所有匿名漏斗的最终转化点。

## §4 数据契约

```typescript
interface LoginContext {
  redirect: string | null;          // 来源页 redirect 参数
  guest_session_id: string | null;  // 来自 P-GUEST-CAPTURE 的 session
  share_token: string | null;       // 来自 P-SHARED 的 token
  consent_accepted: boolean;        // 协议勾选状态
}

interface WechatLoginReq {
  wx_code: string;                  // wx.login() code
  device_fp: string;
  consent_accepted: true;
}

interface WechatLoginResp {
  access_token: string;
  refresh_token: string;
  student_id: string;
  is_new_user: boolean;
}

interface GuestClaimReq {
  guest_session_id: string;
  device_fp: string;                // 必须与 session 创建时同一指纹
}

interface GuestClaimResp {
  claimed_question_id: string;
  review_plan_seeded: boolean;       // T0/T1 节点已写入日历
}
```

## §5 API 触点

| Method | Path | 用途 | P95 预算 | 失败降级 |
|---|---|---|---|---|
| POST | `/api/auth/wechat-login` | 微信授权登录 | 800ms | Toast "登录失败 · 重试" |
| POST | `/api/guest/claim` | claim guest session（如存在） | 600ms | 静默重试 1 次 → 进 P-HOME 提示"稍后可在错题本查看" |
| POST | `/api/share/:token/claim` | claim share token（如存在） | 600ms | 同上 |

## §6 状态机

| State | 触发 | UI 表现 |
|---|---|---|
| `IDLE` | 进入页面 | 主按钮可点 · 协议未勾选时主按钮置灰 |
| `CONSENT_REQUIRED` | 主按钮按下 + consent_accepted=false | Toast "请先勾选协议" + 按钮抖动 + 自动焦点到勾选框 |
| `LOGGING_IN` | 协议已勾选 + 主按钮按下 | Loading Sheet "正在登录..." |
| `CLAIMING` | login 成功 + guest_session_id 存在 | Loading Sheet "正在把刚才的分析保存到错题本..." |
| `SUCCESS` | 全部完成 | 跳 P-HOME（or redirect 目标） |
| `ERROR` | 任意接口失败 | Toast + 留在原状态 |
| `CONSENT_DECLINED` | 用户取消勾选后再点登录 | 同 CONSENT_REQUIRED |

## §9 异常路径

| 触发 | UI | 系统行为 |
|---|---|---|
| 微信授权失败 | Toast "微信登录失败 · 请重试" | 不消耗 token |
| `wx.login` code 已过期 | 自动刷新 code 重试 1 次 | 仍失败则降级 Toast |
| guest_session 已过期（>24h） | 登录成功但 claim 失败 → P-HOME + Toast "刚才的分析已超时" | 不阻塞登录主流程 |
| 设备指纹不匹配 | claim 接口 403 → P-HOME + 错题不入库 | 安全策略：拒绝跨设备 claim |
| 协议链接 webview 加载失败 | 显示静态 "暂时无法查看 · 请检查网络" | 用户可关闭返回 |
| 网络完全失败 | 全屏 ErrorState + "重试" 按钮 | 不跳走 |

## §11 性能预算

- TTI ≤ 600ms（Logo + 按钮可见）
- 微信授权弹起 ≤ 200ms（wx.login 端能力）
- API `/api/auth/wechat-login` P95 ≤ 800ms
- claim 接口 P95 ≤ 600ms
- CLS < 0.05
